Dành cho AI/agent đọc bản đồ này

File graph.json là bản máy-đọc song song: mọi node (data-tier, ce-node, pipeline, model, layer) và edge (produces, reads, flows_to, runs_on, validates, consumes) đều có id ổn định trùng với anchor trong HTML. Quy tắc cho agent:

  • Trước khi chạy bất kỳ test/experiment: xác định đang dùng data-tier id nào (Block 1) và đang ở layer nào (Block 2) — ghi vào RESULT để test không "vô danh data".
  • Trước khi viết script vận hành: tra ce-node hoặc pipeline có sẵn (Block 3) — luật CE-FIRST cấm viết bash driver ad-hoc cho việc nút đã làm được.
  • Mọi khẳng định trong bản đồ có trường evidence (file:line). Nếu sửa hành vi code → cập nhật cả graph.json lẫn HTML.
