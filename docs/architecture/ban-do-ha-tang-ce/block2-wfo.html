Block 2 Luồng Walk-Forward (WFO) — 10 tầng end-to-end

Dòng chảy dữ liệu từ ticker thô đến khi Java HPO/WfoWorker tiêu thụ. Mỗi tầng ghi rõ: code sinh, input, artifact output (tên file thật), grid/cadence, leak-guard, env var, chạy ở node nào. Nguồn sự thật sống: docs/WFO_DATA_PIPELINE_MASTER.md (v1.1.1, 2026-08-04).

✔ NotebookLM đúng "10 tầng" — nhưng thiếu leak-guard & 2 bẫy operator chí mạng Bản này bổ sung: score = 1 − P(win) (đảo dấu ở tầng 8), 2 default nguy hiểm phải override thủ công (WFO_SEL_HORIZON_IDX, WFO_SET_PRED), và bẫy FF_GRID_MIN ≠ LABEL_STEP_MIN làm mất ~93% data khi join mà không báo lỗi.

Chi tiết từng tầng

1️⃣ Ticker (nguồn gốc, đọc-only)

Set: kline_1m_opt (OHLCV per-symbol per-phút). Bất biến: không script nào trong pipeline được ghi vào set này. WFO_DATA_PIPELINE_MASTER.md:46-58

2️⃣ Market layer

Code: DataManagerAerospikeFloatSim.getAllMarketDataFromAerospike() · Input: set market_data · Output: per-minute rateDownAvg / rateUpAvg / rateDown15MAvg. Đây là lưới thời gian "master clock" mà tầng 8 forward-fill mọi nguồn khác lên. MASTER:61-70

3️⃣ OI layer

Code: ExportFundingOiPerCoin.java · Input: OI/long-short/taker-buy per-coin (KHÔNG qua kline_1m_opt) qua getMetricMap226 hoặc source=vision · Output: oi_percoin_<start>_to_<end>.bin.gz, record 30 byte.

Cadence: giữ 5 phút nguyên bản (không phình). Env: OI_TOL_MS default 2h. Leak-guard: floorStale() chỉ nhận điểm ≤t & trong tolerance (không lấy tương lai); oiZ tính EXPANDING. ExportFundingOiPerCoin.java:62-140

4️⃣ Funding LABEL layer

Code: ExportFundingLabel.java · Input: kline_1m_opt + universe alt qua SymbolLifecycleManager (gồm coin chết — chống survivorship; BLOCKED nếu lifecycle rỗng) · Output: funding_label.csv (maxFav/maxAdv/tHitFav/tHitAdv/retEnd/nBars cho H∈{4h,12h,24h,72h,7d,14d,30d}) + sidecar .meta.json.

Grid: LABEL_STEP_MIN default 15, canonical = 1. H_STEPS={240,720,1440,4320,10080,20160,43200} chia LABEL_STEP_MIN. Leak-guard: path chỉ dùng nến trong (t, t+H] — look-ahead ở label là CHỦ Ý (đúng thiết kế H1).

5️⃣ Tool1 feature layer

Code: ExportFeaturesForPythonTool.java · Output: features_export_python_v3/features_*.bin.gz, record 170 byte (ts:long, symId:short, f[40]:float).

2 chế độ: (a) mặc định = production đã qua EntrySignalFilter → KHÔNG dùng train (selection bias); (b) FF_UNFILTERED=1 → mọi alt coin, dùng cho TRAIN selector. Grid (b): FF_GRID_MIN default 15, canonical 1.

⚠ Bẫy nguy hiểm #1 (im lặng)FF_GRID_MIN PHẢI khớp LABEL_STEP_MIN của tầng 4 cùng đợt. Lệch → mất ~93% data khi join (symbol,ts), KHÔNG lỗi KHÔNG crash. MASTER cảnh báo #1

6️⃣ Selector — train + predict (walk-forward, Kaggle)

Code canonical: ml/training/gen_funding_wf_predictions.py (chạy Kaggle — OI merge nặng từng OOM Oracle). Input: TOOL1_GLOB, OI_FILE, LABEL_CSV, MAP_CSV.

Train: XGBoost mỗi (fold, horizon) trên toàn lịch sử expanding từ 2021-01-01, predict OOS block [cutoff, cutoff+OOS_MONTHS). Cutoff canonical FIRST_CUTOFF=20230101. Output: predict_wf_<cutoff>.bin, record 26 byte (>q h 4f: ts, symId, p_4h, p_12h, p_24h, p_72h).

Leak-guard: assert tr.ts.max() < cutoff_ms; purge = H_STEPS["72h"]×GRID_MS (tự tính, không hardcode). CHUNK_YEARS=1 = RAM-bounded (byte-identical với full build).

Lưu ý: train_funding_selector_wfo.py chỉ đo IC/LIFT ổn định per-fold — KHÔNG sinh predict_wf_*.bin cho tầng 8.

7️⃣ Gate layer (ĐỘC LẬP với tầng 4/5/6)

Code: WFOGateRunner.java (điều phối, replay 1 lần → featureStore RAM) + ml/training/train_gate_fold.py (train Python→ONNX per fold) + LoadWfoGatePredTool.java (nạp CSV vào Aerospike).

Feature: 33 feature V3FULL khoá cứng ở OnnxInferenceManager, Python COPY tay (assert thiếu cột). Output: wfo_gate_pred.csv (timestamp,predReturn15M,predRisk4H) → nạp set ai_pred_market_gate_wfo.

L4 provenance ghéppredRisk4H GIỮ từ set CŨ ai_pred_market_full_basket_v2; chỉ predReturn15M là mới → pred OOS = {15M mới + risk4H cũ}, cần ghi provenance từng cột.

8️⃣ WFO dataset export (tầng ráp 3 nguồn)

Code: ExportWfoDataset.java → WfoDataset.export(outDir). Input 3 nguồn: market_data (tầng 2, Aerospike) + set gate ai_pred_market_gate_wfo (env WFO_SET_PRED) + selector predict_wf_*.bin (env WFO_FUNDING_PRED_DIR, đọc THẲNG file — bỏ Aerospike cho funding, Uni chốt 2026-07-08).

Output: market.bin · pred.bin · funding.bin · manifest.txt. Encode: score = 1 − P(win) (đảo dấu — engine chọn score THẤP = P(win) CAO, xác nhận WfoDataset.java:226). forward-fill score 15m→per-minute, staleness cap WFO_FUNDING_FILL_STALE_MS default 15'.

Leak-guard: throw nếu 2 file predict_wf overlap ts, hoặc span > 100 ngày. Manifest stamp leakFreeFrom, codeGitSha (throw nếu "unknown"), horizonIdx, md5+ts-range mỗi file nguồn, VALIDATED_BY=PENDING.

⚠ Bẫy nguy hiểm #2 (2 default sai cho canonical)Default trong code: WFO_SEL_HORIZON_IDX=1 (12h) & WFO_SET_PRED=ai_pred_market_full_basket_v2 (set CŨ). Canonical PHẢI override WFO_SEL_HORIZON_IDX=0 (4h) & WFO_SET_PRED=ai_pred_market_gate_wfo. Quên override = lỗi dễ mắc nhất.

9️⃣ Validate độc lập

Code: scripts/model_quality/validate_canonical_wfo.py — đọc THẲNG bytes, KHÔNG tái dùng code exporter (tránh bug chung). Kiểm 6 nhóm:

  • (a) mỗi fold span ≤ MAX_FOLD_SPAN_DAYS (100) & >0 · (b) OOS sớm nhất ≥ EXPECT_LEAKFREE (fail nếu nhỏ hơn)
  • (c) ts-align: 3 file đều ts%60000==0 · (d) gate coverage: warn nếu ts<leakFreeFrom trong pred
  • (e) NaN horizon đã chọn >50% → warn · (f) không fold nào overlap ts
  • Cross-check manifest: md5 3 file khớp; foldCount khớp; fail nếu leakFreeFrom/codeGitSha="unknown"
Ký fail-closedBất kỳ FAIL → ghi validation_report.txt + sys.exit(1), KHÔNG ký. Chỉ khi TẤT CẢ PASS và SIGN=1 mới ghi VALIDATED_BY=python-validator@<ts>-PASS.
