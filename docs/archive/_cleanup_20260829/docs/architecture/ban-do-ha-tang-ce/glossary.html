Thuật ngữ

SoT (Source of Truth) — kho gốc duy nhất mọi market data = node 242. Off-limits với dev/Kaggle.
WFO (Walk-Forward Optimization) — tối ưu & đánh giá theo cửa sổ tiến dần: train IS → chấm OOS → trượt tới.
Selector — model XGBoost chọn COIN NÀO (P(pump ≥6% trong H)). Output P(win). chi tiết
Gate — model lọc tín hiệu market tổng hợp (predReturn15M), độc lập selector.
score = 1 − P(win) — engine chọn score THẤP; đảo dấu ở tầng 8 (WfoDataset.java:226).
expanding walk-forward — train trên toàn lịch sử ≤cutoff (không windowed), OOS block sau cutoff.
purge / embargo — cắt khoảng quanh cutoff để label tương lai không rò sang OOS (L1 chưa xử đủ).
merge_asof backward — ghép giá trị gần nhất ≤t (không lấy tương lai) → chống leak khi join OI/funding.
ce.cmd <nút> — nút nguyên tử L3, việc chân tay máy làm trọn chuỗi, trả JSON.
llm_gate — step pipeline dừng sạch chờ con người/AI duyệt (điểm TƯ DUY duy nhất).
Result Contract — block === RESULT === chuẩn hoá đầu ra job (STATUS/COMMIT/ARTIFACTS/VERIFY…).
fanout — chạy song song 6-node (2 Oracle + ≤5 Kaggle) cùng jobstore cho full-16-window.
manifest.txt — provenance dataset: leakFreeFrom, codeGitSha, horizonIdx, md5+ts-range mỗi file nguồn.
TICKER_SOURCE — file | aerospike, CHỈ đọc từ config.properties (env NO-OP). chi tiết
